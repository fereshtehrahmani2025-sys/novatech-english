# Novatech – Web Design & Digital Solutions

Novatech is a modern, responsive portfolio website showcasing web design, front-end development, and digital solutions.

The website features a clean, professional interface designed to provide a smooth user experience across desktop, tablet, and mobile devices.

## Features

- Modern and responsive website design
- Clean and intuitive user interface
- Mobile-friendly navigation
- Dedicated About, Services, Portfolio, and Contact pages
- Interactive elements using JavaScript

- Direct email communication
